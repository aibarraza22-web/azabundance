# Water Guess

An interactive, browser-only poll about annual U.S. water use. Participants answer randomized questions with sliders, then compare median guesses, accuracy, and the actual most-to-least ranking.

## Run locally

```bash
cd site
npm run dev
```

## Build and check

```bash
cd site
npm run build
npm run check
```

Poll responses are stored in the browser. A participant can share the poll URL and send their encoded result URL back to the organizer, who can import it into the analysis dashboard.
